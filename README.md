# Whisker Meadow

A cozy 3D cat-sanctuary game prototype for the browser (mobile first).
Earn shy rescue cats' trust with slow, gentle petting, keep them happy,
win ribbons at the cat fair, and help them find loving homes.

**Play:** https://lk1248.github.io/whisker-meadow/

## Files
- `whisker-meadow.html`: the game (single file, Three.js from cdnjs).
- `index.html`: the same game wrapped as a standalone page for GitHub Pages. Rebuild with `python tools/build_index.py`.
- `feedback-notes.md`: design notes and playtest feedback.
